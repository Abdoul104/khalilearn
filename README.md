# **KhaliLearn**  

**KhaliLearn** est une plateforme de formation en ligne qui permet aux apprenants de s'inscrire à des formations, d'accéder à des ressources pédagogiques, et de vérifier leur éligibilité pour obtenir un certificat de fin de formation.  

## **Fonctionnalités principales**  
1. **Gestion des utilisateurs :**  
   - Inscription et connexion sécurisées.  
   - Tableau de bord personnalisé avec informations personnelles, ressources pédagogiques et détails de la formation.  

2. **Certificats et éligibilité :**  
   - Vérification des conditions d'éligibilité directement depuis le tableau de bord.  
   - Validation du certificat avec mention obtenue.  

3. **Ressources pédagogiques :**  
   - Téléchargement des cours et des évaluations.  

4. **Interface utilisateur interactive :**  
   - Menu de navigation responsive.  
   - Système de notification et d'alertes Bootstrap.  

## **Technologies utilisées**  
- **Frontend :**  
  - HTML5, CSS3, Bootstrap 5.  
  - JavaScript (manipulation DOM, sessionStorage).  

- **Backend :**  
  - Fichier JSON pour le stockage des données apprenants.  

- **Bibliothèques externes :**  
  - Bootstrap CDN pour styles et composants interactifs.  

## **Prérequis pour exécuter le projet**  
1. Navigateur moderne (Chrome, Firefox, Edge, etc.).  
2. Connexion Internet (pour les dépendances Bootstrap).
